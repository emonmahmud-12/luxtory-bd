# Luxtory BD — Phase 1 MVP

Static, mobile-first Bengali digital literature platform for GitHub Pages.

## Run locally
Open `index.html` in a browser.

## Deploy
Push the complete folder to a GitHub repository and enable GitHub Pages from the repository's Pages settings.

## Current MVP
- Home / hero
- Search
- Category filtering
- Library cards
- Sample reading modal
- Storytellers section
- Featured authors
- Publish submission UI
- About Emon
- Dark mode
- Responsive mobile-first design

## Not yet implemented
Real accounts, database, admin moderation, persistent submissions, comments, likes, bookmarks, analytics, automated ingestion and server-side search. These require a backend/API.
